# X-Ray THM Tools — 0.4.0-beta

Самостоятельный продукт: плагин просмотра для Total Commander и редактор текстурных THM S.T.A.L.K.E.R. / X-Ray SDK.

## Возможности

- F3 и Ctrl+Q: встроенные миниатюры THM и параметры текстур.
- Просмотр `.object` через соседний одноимённый `.thm`, без рендеринга геометрии.
- Редактор классических текстурных THM версии `0x0012`: поля, флаги, detail, bump, материал и цвета.
- Импорт параметров DDS, создание THM, резервные копии и сохранение неизвестных чанков.
- Edit (F4), Reload, исправленная передача Esc окну Lister.
- Плагин и редактор для x86/x64.

## Установка

1. Скачайте **XRayTHMTools-v0.4.0-beta.zip** из Releases. Исходники для установки не подходят.
2. Откройте ZIP в Total Commander и подтвердите установку плагина.
3. Выделите THM и нажмите F3. Для изменения настроек текстуры нажмите Edit (F4).
4. Настройка F4 из файловой панели описана в [EDITOR_README_RU.md](EDITOR_README_RU.md).

Для обновления полностью закройте TC и замените файлы в установленной папке плагина. Имена `.wlx`/`.wlx64` сохранены от предыдущей сборки.
Подробности: [LISTER_README_RU.md](LISTER_README_RU.md).

## Сборка

Нужны Visual Studio 2022 Build Tools, MSVC v143 x86/x64, Windows SDK и CMake.
В Developer Command Prompt выполните `build.bat` (также работает `build_lister.bat`).
Результат: `dist\XRayTHMTools-v0.4.0-beta.zip` и файл `.zip.sha256`.
Visual Studio пользователям готового пакета не требуется.

## Известные ограничения

В некоторых встроенных миниатюрах виден цветной шум на части картинки. Причина пока не установлена. Наличие миниатюры в текстурном THM допустимо; оно само по себе не означает повреждение файла. Редактор сохраняет существующую миниатюру, но не исправляет и не пересоздаёт её.
Поддержка всех модифицированных SDK не гарантируется. Первое сохранение проверьте на копии файла.

Расширение Проводника XRayTHMThumbnail — отдельный продукт. В этот пакет его DLL и установщики не входят.
