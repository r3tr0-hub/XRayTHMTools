# X-Ray THM Editor 0.4.0-beta

Редактор настроек **текстурного THM версии 0x0012**, отдельное Win32-приложение.
Работает самостоятельно, из Lister и по F4 в Total Commander.
Объектные THM остаются доступны для просмотра; их редактор не изменяет.

## Сборка и установка обновления

1. Распакуйте исходники в `C:\Projects\XRayTHMTools` с заменой исходных файлов.
2. В **Developer Command Prompt for VS 2022** выполните:

   ```bat
   cd /d C:\Projects\XRayTHMTools
   build_lister.bat
   ```

3. Скрипт собирает обе архитектуры и запускает тесты. При успехе появится
   `dist\XRayTHMTools-v0.4.0-beta.zip`.
4. Закройте окна Lister/быстрого просмотра. Для замены загруженного плагина
   полностью закройте Total Commander, распакуйте бинарный ZIP в прежнюю папку
   плагина с заменой файлов, затем снова запустите TC. Сохраните все файлы ZIP,
   включая оба редактора. Если плагина ещё нет — откройте ZIP в TC для установки.
5. Для сборки требуются MSVC v143 x86/x64, Windows SDK и CMake из VS 2022.
   Администратор для редактора и WLX не нужен при установке в доступную пользователю папку.

В бинарном пакете:
- `XRayTHMLister.wlx64` / `.wlx` — просмотр для TC x64 / x86;
- `XRayTHMEditor.exe` — редактор x64;
- `XRayTHMEditor32.exe` — редактор x86;
- `thm_info.exe` — консольный отчёт x64.

## F3 и кнопка Edit

Откройте текстурный `.thm` по F3. Нажмите **Edit (F4)** — откроется редактор.
F4 внутри поля отчёта также обработан плагином, однако TC может перехватывать
клавишу; кнопка остаётся доступна независимо от настройки клавиатуры.
После сохранения нажмите **Reload** в Lister, чтобы обновить отчёт.
Для объектного THM кнопка редактирования отключена.

## F4 из файловой панели Total Commander

F3 запускает Lister, F4 из панели запускает внешний редактор. Настройте его:

1. Запустите `XRayTHMEditor.exe` из установленной папки плагина.
2. Если F4 уже использовался с другим редактором, выберите его `.exe` через
   **Инструменты → Редактор остальных файлов для F4…**.
3. В TC откройте **Конфигурация → Настройка → Правка/Просмотр**.
4. В поле внешнего редактора укажите **полный путь** к `XRayTHMEditor.exe`
   (на 32-битной Windows — к `XRayTHMEditor32.exe`). Например:

   ```text
   "C:\Tools\TotalCommander\Plugins\wlx\XRayTHMLister\XRayTHMEditor.exe"
   ```

   Замените пример на свою папку. В стандартное поле редактора TC передавайте
   только путь к программе: имя выбранного файла Total Commander добавит сам.
5. Выделите текстурный `.thm` в панели и нажмите F4.

Остальные расширения передаются выбранному текстовому редактору, по умолчанию —
Блокноту. Поддерживается путь к EXE без дополнительных аргументов запуска.
`.dds` открывает соседний `.thm` с тем же именем. Если THM отсутствует,
запустите редактор без файла и используйте генерацию. Для `.object` продолжайте
пользоваться F3; F4 этого редактора не редактирует геометрию или миниатюру.

Прямой запуск без TC:

```bat
XRayTHMEditor.exe "D:\ixray\sdk\rawdata\textures\briks\briks_big_01.thm"
```

## Что редактируется

- Все 14 форматов, включая DXT1/ADXT1/DXT3/DXT5, RGB/RGBA и прочие.
- Тип: Image, Cube Map, Bump Map, Normal Map, Terrain.
- Четыре материала и material weight; четыре значения bump mode.
- Все 15 mip-фильтров.
- Все 12 известных флагов, а также полная 32-битная маска с неизвестными битами.
- Border/Fade color как `0xAARRGGBB`; кнопка `…` выбирает RGB и сохраняет alpha.
  Альфа меняется вручную в HEX-поле.
- Fade amount, fade delay, width/height.
- Detail texture и detail scale; bump texture и bump height; external normal map.
- Режим совместимости с ТЧ из THM-Editor: marker + перестановка format/type.

У enum можно ввести неизвестный числовой ID вместо выбора из списка.
Целые поля принимают десятичную запись или `0xHEX`, дробные — точку или запятую.
Fade delay ограничен 0–255, остальные целые сохраняют диапазон uint32.
Редактор не навязывает диапазоны конкретной модифицированной ветки SDK.
Кнопки «Применить настройки типа» и «Флаги по умолчанию» меняют поля только
по явному нажатию. Открытие файла не применяет пресеты автоматически.

Пути к текстурам внутри THM — относительные имена без `.dds`, разделитель `\`.
Кнопки выбора DDS рассчитывают их от папки `textures`; при другой структуре
выберите корень через **Инструменты → Выбрать папку textures…** или введите
имя вручную. Строки внутри THM — Windows-1251, внешние пути файлов — Unicode.

## DDS и создание THM

**Импорт параметров DDS…** переносит размеры, распознанный формат, наличие mipmap,
признак кубической текстуры/альфы и ссылку на соседний `_bump.dds`, если он есть.
Изменения сначала появляются в форме; запись выполняется только при сохранении.
Заголовок DDS не содержит всех исходных настроек SDK, поэтому материал,
фильтр генерации и остальные настройки не восстанавливаются из него.
При неоднозначности DXT1/ADXT1 или неизвестном формате выводится пояснение.

**Создать THM для DDS (+ bump)…** создаёт THM рядом с выбранным DDS и, при наличии,
рядом с его `_bump.dds`. Для каждого используются его собственные размеры и формат.
Перед записью показан список целей; существующие файлы заменяются с копией `.bak-*`.
Неподдерживаемый формат DDS блокирует автоматическую генерацию. Тогда можно
создать новый THM, импортировать размеры и выбрать формат вручную.

Пара из двух файлов не является общей транзакцией: если второй файл не удастся
записать, первый уже сохранён. Сообщение покажет число записанных файлов;
старые версии заменённых файлов останутся в резервных копиях.
Изображение DDS и миниатюра не создаются: генерация касается настроек THM.

## Сохранение и восстановление

- **Ctrl+S** / F5 — сохранить; **Ctrl+Shift+S** / F6 — сохранить как.
- Ctrl+O — открыть, Ctrl+N — новый документ, Esc — закрыть с проверкой изменений.
- Закрытие/смена документа предлагает сохранить несохранённые изменения.
- Без правок файл остаётся побайтно тем же; простое сохранение его не переписывает.
- При изменении записываются затронутые известные чанки; порядок, неизвестные
  чанки, неизвестные биты и существующий чанк миниатюры сохраняются.
- Перед заменой исходник сверяется со снимком при открытии. Если файл поменяла
  другая программа, сохранение отменяется: откройте его заново либо «Сохранить как».
- Запись идёт во временный файл рядом с исходником, затем применяется ReplaceFile.
  При замене создаётся резервная копия `имя.thm.bak-дата-время-счётчик`.
- Для восстановления закройте редактор и замените THM нужной резервной копией.
  Копии не удаляются автоматически.

## Дополнительная интеграция

В «Инструментах» можно добавить/убрать команду «Редактировать THM» в меню
Проводника для текущего пользователя. Основная ассоциация `.thm` не меняется.
Перед переносом редактора уберите команду и добавьте её заново из новой папки.
Настройки хранятся в `%APPDATA%\XRayTHMTools\editor.ini`.

## Ограничения и проверка выпуска

Классический texture THM 0x0012, до 4 MiB/1024 чанков. Неизвестная версия,
дубли чанков, сжатые/расширенные известные metadata-чанки и нечисловые float
блокируют редактирование. Неизвестные отдельные чанки разрешены и сохраняются.
Встроенный просмотр модели/DDS, массовая обработка папок и изменение картинки
THM в эту версию не входят.

Портируемая часть проверена на предоставленном текстурном THM и синтетических данных:
побайтовый roundtrip, все поля, неизвестные чанки, SoC, DDS, повреждённые входы.
Код редактора и Lister прошёл перекрёстную компиляцию/линковку x64 и x86.
Windows UI, связка с Total Commander и Windows API сохранения в среде разработки
не запускались. Windows-тесты включены в build_lister.bat и GitHub Actions.
Первая сборка остаётся beta до проверки на Windows; начните с копии текстурного THM.
