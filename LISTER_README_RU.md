# X-Ray THM Lister — 0.4.0-beta

Плагин просмотра (WLX) для Total Commander, F3 и Ctrl+Q.

## Что показывает

- Объектный THM: встроенную миниатюру 128×128 и информацию о чанках.
- .object: миниатюру из соседнего .thm с тем же именем. Геометрия объекта
  не читается и не рендерится. Если THM отсутствует, показано сообщение.
- Текстурный THM: параметры формата, размеров, флагов, mip-фильтра,
  detail-текстуры, материала, bump, external normal map и fade delay.
- Fit / 100% / 200%: масштаб отображения, ограниченный доступной областью окна.
- Copy report: копирование отчёта целиком; текст можно выделять и копировать.
- Enum показываются с названиями; флаги — с именами и исходной маской.
- Неизвестные чанки остаются видны в отчёте.
- **Edit (F4)** открывает текстурный THM в отдельном редакторе.
- **Reload** перечитывает файл после сохранения.

Сам Lister читает файлы; изменения сохраняет XRayTHMEditor.
Редактирование и настройка F4 описаны в [EDITOR_README_RU.md](EDITOR_README_RU.md).

## Установка

1. Скачайте XRayTHMTools-v0.4.0-beta.zip (готовый бинарный пакет).
2. В Total Commander откройте этот ZIP двойным щелчком. pluginst.inf
   позволяет TC предложить установку Lister-плагина. Подтвердите установку.
3. Если предложения нет: распакуйте пакет, откройте «Конфигурация → Настройка →
   Плагины → Плагины просмотра (WLX) → Настроить → Добавить».
   Названия пунктов могут немного отличаться в вашей локализации.
4. Для 64-битного Total Commander выберите XRayTHMLister.wlx64,
   для 32-битного — XRayTHMLister.wlx.
5. Выделите .thm или .object и нажмите F3; Ctrl+Q открывает быстрый просмотр.

Разрядность плагина должна совпадать с Total Commander, а не только с Windows.
Для установки плагина в доступную пользователю папку администратор не нужен.


## DDS по желанию

Загрузчик также умеет брать настройки из соседнего THM при открытии .dds,
но правило автоопределения намеренно ограничено THM и OBJECT. Чтобы включить
этот режим, в настройках Lister-плагина задайте:

    EXT="THM" | EXT="OBJECT" | EXT="DDS"

Это может заменить привычный просмотр DDS данным плагином. Он показывает
настройки из THM, а не картинку DDS. Без соседнего THM будет сообщение ошибки.
По умолчанию существующий просмотр DDS не перехватывается.

## Сборка исходников

Установите Visual Studio 2022 Build Tools с MSVC v143 x64/x86, Windows SDK
и CMake. В x64 Native Tools Command Prompt перейдите в папку исходников:

    build_lister.bat

Скрипт соберёт обе архитектуры, прогонит тесты разбора и сформирует:

    dist\XRayTHMTools-v0.4.0-beta.zip
    dist\XRayTHMTools-v0.4.0-beta.zip.sha256

В CI новый job lister также собирает этот архив как artifact.
Исходный ZIP сам по себе не устанавливается в TC и не содержит WLX-бинарников.

## Проверка и диагностика

    thm_info.exe "D:\textures\briks_big_01.thm"

thm_info.exe — 64-битная консольная утилита отчёта. Для неё нужна Windows x64,
даже если используется 32-битный Total Commander.

Сравните поля с SDK на нескольких THM. Проверьте F3, Ctrl+Q, закрытие окна,
изменение размера, переход между файлами и два окна Lister одновременно.
Unicode API поддерживает кириллицу в путях; строки внутри THM читаются CP1251.
Чтобы обновить WLX, полностью закройте Total Commander, замените файл
и снова запустите TC. Удаление: отключите плагин в списке WLX и после
закрытия TC удалите его папку.

Проверено в среде разработки: ваш текстурный THM 185 байт, декодирование
barikada_01.thm, синтетические контейнеры, битые поля и тысячи повреждённых
входов с ASan/UBSan. Код редактора и плагина скомпилирован и слинкован для Windows x64/x86
перекрёстным компилятором. MSVC-сборка и работа в TC здесь не запускались.
Первую версию нужно проверить на вашем Total Commander; выпуск остаётся beta.

## Поддержка формата

Классическая версия 0x0012. Неизвестная версия показывает сырые чанки,
не выдавая её значения за известные настройки. Ошибки отдельных полей
не скрывают остальные чанки. Ограничение входа 4 MiB и 1024 чанка.
Сжатые metadata-чанки не интерпретируются; превью поддерживает старый
LZSS/adaptive-Huffman. LZO не реализован.

Модель texture::Document сохраняет исходные байты и меняет только затронутые
чанки. Редактор доступен для классических текстурных THM версии 0x0012.
Подробности и ограничения — в EDITOR_README_RU.md и FORMAT_NOTES.md.
